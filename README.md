## 💡 为什么做这个项目？

在《幻唐志》（原神武）等 2.5D 回合制网游中，战局瞬息万变，关键回合的伤害量、治疗溢出、集火效率全靠指挥与队员凭肉眼与心算捕捉。

现有的方案通常存在致命缺陷：
- **内存读写 / DLL 注入**：极易触发游戏反作弊机制，导致封号。
- **封包解密**：协议加密升级频繁，维护成本高且违规风险巨大。
- **纯本地 OCR 读屏**：特效遮挡严重、怪名与技能名同色、等级前缀干扰过多，**误检率高达 70%~85%**。

**本项目采用全新技术路线**：
> **「本地 CV 边缘过滤（高召回、低开销、不联网） + 云端多模态大模型验证（高精准、懂语义） + 回合状态机切分」**
> 
> 纯外挂视觉读屏，**零内存侵入、不改包、不模拟按键点击**，兼顾极致安全性与实战可用性。

## 🌟 核心特性

- 🛡️ **绝对安全（零封号风险）**：基于无侵入式截屏（`mss`），不读取/修改任何游戏进程内存，不注入 DLL，不发送虚拟鼠标键盘事件。
- ⚡ **分层计算架构**：
  - **本地端（87ms/帧，零成本）**：特定颜色族掩码提取 + 连通域轮廓分析 + RapidOCR 候选初筛，保证高召回率（实测真值召回 9/9），只在产生大数字跳字时才触发上传。
  - **云端端（多路并发 VLM）**：使用 Qwen-VL-Max 等视觉模型读整帧，精准剔除误检（如怪名、特效、等级数字），推断伤害类型与单位归属。
- 📊 **回合级精确聚合**：自动 OCR 顶栏「第 N 回合」，实现回合级状态机切分与跨帧滑动窗口去重。
- 📱 **双端实时面板**：
  - **PC 悬浮窗**：置顶半透明 HUD 浮窗，实时刷新当前回合伤害排名。
  - **移动端局域网看板**：启动时终端打印二维码，手机连同一 Wi-Fi 扫码即开 `panel.html`，无需安装任何 App。
- 💰 **极致成本控制**：单场 138 秒的高强度战斗仅触发约 27~38 次云端验证，单场综合成本仅约 **¥0.3 ~ 0.5**。

## 🚀 快速启动

### 方式 A：Windows 玩家双击即用（推荐）

1. **安装 Python**：
   - 前往 [Python 官网](https://www.python.org/downloads/) 下载 Python 3.11 或更高版本。
   - ⚠️ **安装时务必勾选：`Add python.exe to PATH`**（若漏勾将无法在命令行调用）。

2. **配置密钥**：
   - 复制项目根目录下的 `config.example.txt` 为 `config.txt`。
   - 填入你的云端大模型 API Key（详见下方 [API 配置说明](#-云端-api-配置)）。

3. **双击启动**：
   - 双击根目录下的 **`1-启动.bat`**。
   - 首次启动会自动创建虚拟环境、配置清华镜像加速并安装所需依赖。
   - 交互控制台界面支持：
     - `1) 实时统计`：进入主战斗统计循环（可开启桌面悬浮窗 + 局域网网页）。
     - `2) 抓屏预览`：检查截屏区域是否正确对齐游戏窗口。
     - `3) 检查 API`：测试云端大模型连通性与余额。
     - `5) 离线测试`：不耗费 API 额度，验证本地数字识别管线。

### 方式 B：开发者模式（CLI / macOS / Linux）

```bash
# 1. 克隆代码仓库
git clone https://github.com/bochuj238-bit/htz-battle-stats.git
cd htz-battle-stats

# 2. 创建并激活虚拟环境
python3 -m venv .venv
source .venv/bin/activate  # Windows 用户: .venv\Scripts\activate

# 3. 安装依赖（推荐清华镜像）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 配置环境变量
export VLM_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxx"
# 也可以配置：export VLM_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
#            export VLM_MODEL="qwen-vl-max"

# 5. 验证 API 连通性
python tools/check_api.py

# 6. 运行方式（录像离线测试 或 真实截屏）
# A) 本地录像仿真回放测试（--mock 表示不消耗 API）：
python tools/runner.py --source video:test.mp4 --fps 5 --speed 6 --mock

# B) 真实屏幕抓取监控：
python tools/runner.py --source screen --monitor 1 --fps 5
# 指定只抓游戏窗口区域（更高效、低噪点）：--region x,y,w,h
```

## 🔑 云端 API 配置

本工具使用 **OpenAI 兼容协议** 调用视觉大模型（Vision Language Model）。市面上主流多模态模型均可即插即用：

| 平台 | Base URL | 推荐模型 | 特点 |
|---|---|---|---|
| **阿里云百炼 (DashScope)** ⭐ | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-vl-max` | **实测效果最佳**，新用户有免费额度 |
| **硅基流动 (SiliconFlow)** | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-VL-72B-Instruct` | 极速响应，性价比极高 |
| **智谱 AI (BigModel)** | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-plus` | 兼容 OpenAI 格式 |

> 💡 **如何获取通义千问 API-Key：**
> 1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)。
> 2. 依次点击：**模型服务** → **API-KEY 管理** → **创建我的 API-KEY**。
> 3. 将生成的 Key 填入 `config.txt` 中的 `VLM_API_KEY=` 字段。

## 🎨 标定参数速查

所有关键颜色阈值均已在 `tools/detect_numbers.py` 中完成物理标定：

| 画面视觉元素 | 颜色与特征 | 排除 / 判定逻辑 |
|---|---|---|
| **伤害飘字** | 亮橘红色，`H 0~35, S>120, V>180` | 本地连通域捕获，标记为 `damage` 候选 |
| **治疗飘字** | 荧光绿色，`H 35~80, S>120, V>180` | 本地连通域捕获，标记为 `heal` 候选 |
| **单位等级前缀** | 纯白色字样（如 `140`） | 统计框内白色（高亮低饱和）像素比，`>55%` 直接拒识 |
| **固定 HUD/聊天框** | 静态无描边嫩绿文字 | 20 帧在线持久化坐标过滤 + 局部排除区 |
| **顶栏回合指示** | 阴影金黄色「第 N 回合」 | 模板定位，用于驱动回合状态机自增 |

## ⚠️ 已知限制与注意事项

1. **画面遮挡与光效爆炸**：在全屏特写技能或极强光效覆盖期间，数字飘字可能被完全遮盖产生瞬态漏检。
2. **2.5D 视角下的重叠归属**：部分同名单位或前排重叠站位时，数字可能压在后排单位上方，目前的水平对齐归属算法仍有少数边缘情况待优化。
3. **录屏采集设置**：若使用 OBS 或采集卡辅助抓流，请务必选择 **「显示器采集」** 或 **「窗口采集」**，切勿使用「游戏采集」（游戏采集会挂钩注入目标进程）。
