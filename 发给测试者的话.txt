【幻唐志战斗统计工具 · 测试版】

麻烦你帮我试试这个工具，大概 10 分钟。有问题随时拍给我，不用怕烦。

━━━━━━━━━━━━━━━━━━━━━━
一、装 Python（只做一次）
━━━━━━━━━━━━━━━━━━━━━━
1. 打开 https://www.python.org/downloads/
2. 下载 Python 3.11 或更高版本
3. ⚠️ 安装时务必勾选 ☑ Add python.exe to PATH
   这步漏了后面全跑不起来，一定要勾

（已经装过 Python 就跳过这步）

━━━━━━━━━━━━━━━━━━━━━━
二、解压 + 启动
━━━━━━━━━━━━━━━━━━━━━━
1. 把 zip 解压出来（别直接在压缩包里双击）
2. 双击 1-启动.bat
   - 第一次会自动装依赖，大概 2~5 分钟
   - 看到「✓ 依赖装完了」就是好了
   - 它可能会问 API key：直接回车跳过（我已经填好了）
   - 如果界面显示「API key: 已配置」就对了

━━━━━━━━━━━━━━━━━━━━━━
三、先做这两步（不花钱、不联网）
━━━━━━━━━━━━━━━━━━━━━━
【菜单 2】抓屏预览
    → 会弹出一张图。图里正好是游戏画面 = 设置对了
    → 如果是一片纯黑 = 游戏得改成「窗口化」或「无边框窗口」

【菜单 5】离线测试
    → 不联网、不花钱，看它能不能认到你机器上的数字
    → 会滚动打印类似「t=12.5s 第1回合 触发 #3 1546(wa72px)」
    → 按 Ctrl+C 停

━━━━━━━━━━━━━━━━━━━━━━
四、正式试一场（这个要联网）
━━━━━━━━━━━━━━━━━━━━━━
1. 游戏调成「窗口化」或「无边框窗口」（别用全屏，全屏抓不到）
2. 进一场战斗
3. 双击 1-启动.bat → 菜单 1) 实时统计 → 显示方式选 1（电脑悬浮窗）
4. 屏幕右上角会出现一个小窗，打起来后自动显示数字
5. 打完按 Ctrl+C 停

━━━━━━━━━━━━━━━━━━━━━━
五、麻烦告诉我这些（最重要的部分）
━━━━━━━━━━━━━━━━━━━━━━
1. 你的电脑：Windows 几？屏幕分辨率？游戏是窗口化还是全屏？
2. 「装依赖」那步顺利吗？报错的话把黑窗口截图给我
3. 抓屏预览：图里是游戏画面，还是黑的？
4. 离线测试：有没有滚动打印触发？有截图最好
5. 正式那一场：
   - 悬浮窗出来了吗？挡不挡操作？大小位置合不合适？
   - 数字准不准？跟你游戏里看到的对一遍，大概几成对？
   - 有没有明显漏掉的伤害？
6. 任何觉得别扭、看不懂、卡住的地方都告诉我，越具体越好

━━━━━━━━━━━━━━━━━━━━━━
说明
━━━━━━━━━━━━━━━━━━━━━━
· 这工具是「看屏幕」的：截图 + 图像识别，不读内存、不改游戏、不模拟点击
· 录屏别用 OBS 的「游戏采集」（那个会注入进程），要用「窗口采集」
· 这一场大概花 3~5 毛钱 API 费用，我出，你随便测
· 详细说明在同目录的「使用说明.md」
